# Тестовые шаблоны

Два DOCX-шаблона по образцу протоколов тендера, у каждого — наборы данных для ручной проверки шаблонов и выпуска DOCX/PDF. Все организации, люди и БИН вымышленные (у БИН правильная контрольная цифра).

| Папка | Документ | Что проверяет |
|---|---|---|
| `opening/` | Протокол вскрытия заявок (ашу хаттамасы), 4 стр. | значения, таблицы с циклом по строкам, цикл по абзацам с таблицей внутри (документы каждого участника), `{{else}}` для пустого списка, форматтеры, метка в колонтитуле |
| `results/` | Протокол об итогах (қорытындылар туралы хаттама), 8–10 стр. | вложенные циклы (участник → члены комиссии), `{{#if}}` внутри ячейки, многострочный текст из `\n`, `{{#if}}…{{else}}` для исхода тендера, поля только в невыбранной ветке |

В каждой папке:

- `template.html` — исходник шаблона; `template.docx` — сам шаблон (его можно открыть и поправить в Word).
- `data.json` — основной набор, похожий на настоящий протокол.
- `data-edge.json` / `data-winner.json` — другой путь по шаблону (см. ниже).
- `data-invalid.json` — ошибки в данных: сервис должен отказать `400 invalid_data` и перечислить их.

## Как запустить

Нужны `make up`, `make run` и ключ портала (`make keygen ...`).

```bash
export DOCGEN_KEY=dg_...
examples/try.sh examples/opening
examples/try.sh examples/results
```

Скрипт проверяет шаблон (`/v1/templates/check`), выпускает документ по каждому `data*.json` в DOCX и PDF и раскладывает результаты в `examples/out/<папка>/` (папка в `.gitignore`). При ошибке он печатает её код и список полей.

Один набор или свой шаблон:

```bash
examples/try.sh examples/results data-winner.json
examples/try.sh ~/Документы/мой_шаблон.docx ~/Документы/данные.json
```

Каждый запуск — новый документ (новый `Idempotency-Key`); все они видны в журнале админки.

## Что смотреть

Открыть DOCX в Word или LibreOffice и PDF в просмотрщике. В обоих должно быть одно и то же.

**opening / data.json** — 4 страницы, альбомная A4; сначала казахская часть, затем русская с новой страницы.
- В колонтитуле: `100778-3-ОТ` слева, «стр. / бет N / 4» справа.
- Комиссия: 5 строк с номерами 1–5.
- Сумма `6 000 000.00` и прописью: «Алты миллион теңге 00 тиын» / «Шесть миллионов тенге 00 тиын».
- Лот: количество `1`, цены `6 000 000.00`.
- Участники: 3 строки; БИН `210640011783` (в данных число) и `220740021944` (в данных с дефисами) напечатаны одинаково; время `20.10.2026 11:32:45` (в данных `+05:00`).
- Документы участников: три таблицы с 9, 5 и 2 строками, ☒ и ☐ по данным.
- Примечание — текст по умолчанию (в данных `null`).

**opening / data-edge.json** — 4 страницы.
- Время вскрытия `02.11.2026 14:00:00` (в данных `09:00Z`, UTC → Алматы).
- Сумма `1 234 567.89` (из `1234567.891`), прописью «…пятьсот шестьдесят семь тенге 89 тиын».
- Количество `2 500.75`, цена `103.33` и `650.50`.
- «Дополнительная характеристика: —» у обоих лотов (`null` и `""`).
- Адрес участника в две строки (`\n`).
- БИН `000740001307` (в данных число `740001307`).
- У участника нет документов — строка «Документы не представлены».
- Примечание — текст из данных.

**opening / data-invalid.json** — `400 invalid_data`, 7 ошибок: дата не в формате, нет `customer.name_kk`, `commission` не список, `total` не число (для `money` и `moneywords`), неверный БИН, `provided` не true/false.

**results / data.json** — 10 страниц, тендер несостоявшийся.
- Запросы: строка «Берілген өтінімдер жоқ.» / «Нет предоставленных заявок.» (пустой список).
- Голосование: 3 таблицы по 4 члена комиссии; у первого участника везде «өткізілді / допущен» и прочерки, у двух других — «қабылдамау / отклонен», причина и многострочное обоснование.
- Отклонено 2, допущен 1; скидки `3.00` / `1.93` напечатаны как в данных.
- Условные цены: `3 422 160.00`, `3 182 085.00`, `5 393 850.00`.
- Итог: «…несостоявшейся в связи с тем, что к участию в тендере допущен один потенциальный поставщик.»

**results / data-winner.json** — 8 страниц, тендер состоялся.
- Запросы: 2 строки, у второго «жауап жоқ / ответа нет» (`answered_at: null`).
- Все члены комиссии допустили всех; «Отклонённых заявок нет»; допущены 3.
- Итог: «…состоявшейся. Победитель: … «БЕТА КОНСАЛТ ТЕСТ» (БИН 210640011783), сумма договора 3 280 500.00 тенге (три миллиона двести восемьдесят тысяч пятьсот тенге 00 тиын).»

**results / data-invalid.json** — `400 invalid_data`, 7 ошибок: у члена комиссии нет `admitted`, нет `rejected_count`, цена не число, и `failed: false` при `winner: null` — четыре ошибки по полям `result.winner.*`, которые нужны ветке «состоялся».

## Свой шаблон

1. Взять `template.docx`, открыть в Word, поменять текст или оформление, добавить метки (`{{ поле }}`, `{{ поле | money }}`, `{{#each список}}…{{/each}}` — синтаксис в README репозитория).
2. `examples/try.sh путь/к/шаблону.docx examples/opening/data.json` — если нужны новые поля, добавить их в копию JSON.
3. Ошибка шаблона (`422`) называет метку и где она; ошибка данных (`400`) — путь к полю.

## Пересборка из HTML

После правки `template.html`:

```bash
python3 examples/build.py
```

Нужен LibreOffice (`soffice`). Скрипт делает страницу альбомной A4, сужает колонку «№» и добавляет колонтитул с `{{ number }}` и номерами страниц. Если шаблон правили в Word, пересобирать не нужно: правки в `template.docx` перезапишутся.
